# T-shirt Master Asset Notes

## Source

The runtime assets for this folder were derived from the supplied Dual Side T-shirt Artwork Mockup.psd.

The original PSD is intentionally not stored in this repository because it is a 232 MB source file and is not required by the web application.

## Detected useful PSD layers

- Tshirt
- Tshirt Color Front
- Tshirt Color Back
- Design Front
- Design Back
- Place Your Front Design Here
- Place Your Back Design Here

## Current implementation decision

The source provides separate front/back garment color masks, but not independent masks for every garment section. Phase 2B will therefore start with front/back recoloring and will only add finer section controls after accurate masks are available.
